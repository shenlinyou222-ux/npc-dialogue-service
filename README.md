# npc-dialogue-service

角色对话 NPC 的数据工程、微调与评测管线（**不含模型权重、不含语料全文**）。

## 这个仓库解决什么问题

游戏 NPC 用通用大模型说话会出三个问题：**说话不像角色**、**编造世界观**、
**输出带旁白和括号动作**（`（她笑了笑）` 这种，进不了对话框）。

本项目把这三件事拆成可验证的三段：

1. **语料工程**：从公开 Wiki 采集剧情对话 → 清洗去重 → 按「连续发言游程」重切成对话片段
2. **微调**：在 Qwen3.5-0.8B 上做 LoRA（7 或 10 个 target 模块），
   约束成「短句、口语、无旁白、无括号」
3. **评测**：格式通过率 / 口癖密度 / 延迟 p50 / 幻觉中招率

## 目录

| 目录 | 内容 |
|---|---|
| `dataset/` | 数据集构建与质检脚本 + 统计 + 20 条抽样预览（**不含全文**） |
| `train/` | 切分（按 mission 防泄漏）、清洗、LoRA 训练脚本 |
| `eval/` | 对照演示、口癖统计、数据来源审计 |
| `eval/results/` | 评测结果原始 JSON |
| `lore/` | 专名表（世界知识） |

## 已知边界

- **没有生产规模经验**：单机 8GB 单卡，无并发压测
- **语义会错位**：5 条场景里 2 条答非所问（听见了但答的不是那个问题）
- **长度偏短**：平均 11 字，训练数据是 22 字
- **幻觉未根治**：无检索增强时仍会编设定
- **权重不公开**：受角色 IP 与语料版权约束，权重仅本地保留

## 复现

```bash
# 1. 切分（需要语料，仓库不提供）
python train/prepare_data.py --src <语料.jsonl> --out data/

# 2. 清洗混合
python train/clean_build.py

# 3. 训练
python train/train_lora.py --data /path/to/m7mix --epochs 3 \
    --bs 8 --accum 2 --lr 1e-4 --r 16 --alpha 32

# 4. 评测
python eval/demo_compare.py --adapter <adapter_dir>
```
